# Priming Songs

A specialized guide for one type of song: research/priming songs. It builds on the base songwriting grammar in `suno guide songwriting` — that guide teaches section tags, meta-tags, vocal direction, and structure; this one teaches how to layer evidence-graded psychological priming into a lyric and ship it as a research artefact.

Every output here is two things at once: a Suno-ready song **and** a research artefact — a Prime-Stack Map, evidence grades, a selection rationale, and a predicted effect with honest confidence intervals. If you produce the song without the artefact, you have not done the task.

---

## Consent and ethics — read this first

This is a **consent-based research programme**. Priming songs are built for people who have agreed to be studied, or for anonymised experimental batches. The ethical frame is load-bearing, not decorative — it determines what you will and will not build.

**Two valid configurations, and only two:**

1. **Named consenting target.** A specific person has agreed to be the target of a charm / priming attempt, usually inside an existing relationship. The song is a gift and an experiment they are a co-participant in. (Example frame: a named-target charm round for a specific brand, with the target's prior invitation.)
2. **Anonymised batch experiment.** Participants recruited with informed consent, randomised to conditions, hearing songs described as "lounge music" during a broader task. Standard IRB-equivalent framing. A debrief afterwards discloses the priming intent and the research question.

**What makes this ethical:**
- Consent — informed, or explicit invitation by the named target.
- Debrief — participants understand what they were part of.
- No real financial or medical stakes tied to the outcome of the priming.
- Right to withdraw and have data removed.

**What makes it unethical — refuse and redirect:**
- Targeting a named non-consenting third party.
- Using the output to induce real high-stakes decisions (actual investment, medical adherence, political vote) under deception.
- Not debriefing batch participants.
- Collecting identifiable data without consent.

Do not re-litigate this frame on every request — the default assumption is consent-based and you should proceed. Only stop and redirect when a request explicitly targets an unaware third party for real harm. If a scenario crosses into unethical territory, say so plainly and redirect to a consent-based design.

### The honest-claims discipline

The single most important craft rule after consent. Stacked priming on aligned, consenting listeners produces **small effects**. State them honestly or the work is worthless — reviewers who know the literature will dismiss overclaims instantly.

- Attitude shifts: **d ≈ 0.1–0.3.**
- Brand/product recall: **d ≈ 0.4–0.6.**
- Behavioural change (actual action): **d ≈ 0.0–0.15** — the intention-behaviour gap is real; never claim more.
- **Ordering rule:** never claim behaviour change > attitude change > recall in any rationale. Recall is the strongest, honest outcome; behaviour is the weakest.

### The evidence-grading rule

Every load-bearing prime must carry an **evidence grade** from the literature below.

- **Grade B or higher** for load-bearing primes.
- **Grade C** acceptable for atmospheric / decorative use only.
- **Grade D–F** are never claimed as working primes. They may appear only as deliberate **null probes** in a controlled design comparing robust vs. debunked primes.

---

## Core principles

1. **Evidence grading, not vibes.** Every prime is selected from the graded library, not from persuasion folklore.
2. **Small effects, honest claims.** See above. Calibrated priors, always.
3. **Subtlety via craft, not effect-size magic.** Good masking comes from lyrical flow, not from invoking debunked "subliminal" lore. *Stealth means "requires attention to detect", not "below perceptual threshold."* Sub-threshold subliminal effects on complex behaviour do not exist (Pratkanis 1992).
4. **Document or it didn't happen.** No unmapped primes. Every line is traceable to a prime or is explicitly flagged as pure genre anchor.

## Inputs

Collect these; infer from prior turns; don't re-ask what's already given.

- **Target** — named person (enables phonetic wordplay) OR anonymised batch descriptor (≥3 attributes: role + domain + psychographic).
- **Priming objective** — a specific, falsifiable attitude or action.
- **Domain** — investment / marketing / sales / political / health / other.
- **Genre & mood** — default **chill lounge, ~72 BPM** (low-arousal → parasympathetic state → lower critical evaluation at the bridge).
- **Subtlety dial** — overt / medium / stealth. Default medium if unspecified.
- **Wink references** — the target's own cited memes, quotes, frameworks.

---

## Two modes

**Mode A — single-draft (fast).** Quick iterations, prototypes, one-off tests.
1. Collect inputs.
2. Select 4–6 primes from the Literature section (Grade B+).
3. Design name embedding via the Phonetic Wordplay section.
4. Pull domain vocabulary from the Prime Libraries section.
5. Draft with the pre/generation/post gates from the Quality Checklist.
6. Emit with the Prime-Stack Map + rationale.

**Mode B — multi-agent (paper-eligible).** Live tests on real targets, songs that enter the dataset, anything flagged "for the paper" or "high quality." Full orchestration in the Multi-Agent Protocol section below.
1. Brief sent in parallel to Cognitive Scientist, Poet, Musicologist — each produces a candidate draft with independent prime choices.
2. Phoneticist audits name embeddings across all three.
3. Red Team simulates blind detection, flags detectable primes.
4. Synthesiser picks best lines, produces final + selection memo.
5. Pre-register predictions **before** generation.

Default to Mode A. Switch to Mode B on user signal or when the song is destined for live testing.

## Literature: mechanisms, evidence grades, citations

The substantive backbone. Every prime used in a song must come from the Grade A–B tier unless it is deliberately deployed as a null probe.

### Replication-crisis context (read before selecting primes)

Social priming underwent a major replication crisis from ~2011. Many famous effects failed to replicate, or replicated far smaller than reported. **Do not invoke these as load-bearing primes** — they sound persuasive but discredit the work:

- **Bargh, Chen & Burrows 1996** — "elderly stereotype" → slower walking. Failed replication (Doyen et al. 2012; Shanks et al. 2013). Original effect likely experimenter expectancy.
- **Vohs, Mead & Goode 2006** — money priming. Meta-analysis (Lodder et al. 2019, n > 21,000) found the effect indistinguishable from zero.
- **Dijksterhuis & van Knippenberg 1998** — "professor priming" → better trivia. Failed replication (Shanks et al. 2013).
- **Kay et al. 2004** — objects-in-room priming of competitive vs. cooperative behaviour. Replication mixed at best.
- **General subliminal advertising** ("drink Coke" frames) — classic debunking (Pratkanis 1992); effect essentially zero for complex behaviour.

Use only Grades A–B as the engine. Grade C is supporting imagery. Grade D–F stay out or appear only as controlled null probes.

### Evidence-grading schema

| Grade | Meaning |
|---|---|
| A | Multiple high-powered replications, meta-analytic support, mechanism understood |
| B | Replicated, moderate effect size, some boundary conditions known |
| C | Replicated with caveats, context-dependent, modest effect |
| D | Original study only, not yet replicated — treat as hypothesis |
| F | Failed replication or meta-analytic null — do not claim as a working prime |

### Primes by mechanism

#### Attention capture

**Cocktail-party effect (own-name attention) — Grade A**
- Effect: hearing one's own name biases attention and triggers mild positive affect.
- Evidence: Moray 1959 (selective-attention origin); Wood & Cowan 1995 (modern replication with controls); Holeckova et al. 2006 (fMRI: distinct neural response to own name even during sleep); Perrin et al. 2005 (coma patients show differential response).
- Effect size: moderate for attention capture (unattended-channel detection rises from ~10% to ~35% when the name appears); affect effect smaller, d ≈ 0.2.
- Boundary: strongest when the name is distinctive and in the listener's native accent.

**Mere exposure — Grade A**
- Effect: repeated exposure increases liking, even without conscious recall.
- Evidence: Zajonc 1968 (original); Bornstein 1989 meta-analysis (d ≈ 0.26 across 208 studies); Monahan, Murphy & Zajonc 2000 (subliminal mere exposure works for simple stimuli).
- Effect size: d ≈ 0.2–0.3 for liking; larger (d ≈ 0.4–0.6) for recognition/recall.
- Boundary: inverted-U — over-exposure causes satiation past ~10–20 reps in a short window; stronger for initially neutral than negative stimuli. **This is the engine of brand recall.**

#### Belief shaping

**Rhyme-as-reason — Grade B**
- Effect: rhymed aphorisms are rated more accurate than non-rhymed equivalents.
- Evidence: McGlone & Tofighbakhsh 2000 (original); replicated in several contexts; part of the broader processing-fluency family.
- Effect size: small–moderate, d ≈ 0.3.
- Use: place load-bearing claims on rhymed chorus lines.

**Processing fluency — Grade A**
- Effect: easier-to-process statements are judged more true, more likeable, more familiar.
- Evidence: Reber, Winkielman & Schwarz 1998; Alter & Oppenheimer 2006 (stock-ticker fluency); Alter & Oppenheimer 2009 review.
- Effect size: moderate, d ≈ 0.3–0.5 for truth judgments.
- Use: simple vocabulary, predictable meter, familiar phrasing in the hook.

**Anchoring — Grade A**
- Effect: numeric or categorical anchors bias subsequent judgment.
- Evidence: Tversky & Kahneman 1974; Chapman & Johnson 1999; Epley & Gilovich 2006 (self-generated anchors); meta-analysis Li et al. 2022.
- Effect size: large, d ≈ 0.5+ in judgment tasks.
- Use: concrete numeric imagery ("tenfold", "half past gold") in high-salience positions.

**Ease of retrieval (availability) — Grade B**
- Effect: the ease of bringing examples to mind influences frequency/likelihood judgment.
- Evidence: Schwarz et al. 1991; Tversky & Kahneman 1973.
- Effect size: moderate.
- Use: repeat positive-outcome imagery so examples feel available.

#### Persuasion framing

**Social proof via narrator identification — Grade B**
- Effect: a first-person success narrator is mapped onto by the listener.
- Evidence: Bandura 1977 (observational learning); Green & Brock 2000 (narrative transportation); De Graaf et al. 2012 meta-analysis on narrative persuasion (r ≈ 0.22).
- Effect size: moderate, d ≈ 0.3–0.4.
- Use: V2 in first-person voice describing an outcome already achieved.

**Loss-aversion framing — Grade A**
- Effect: equivalent outcomes framed as losses weigh more than gains; reframing as "no loss" disarms.
- Evidence: Kahneman & Tversky 1979; Tversky & Kahneman 1981; many replications.
- Effect size: large for framing, loss:gain coefficient ≈ 2.25.
- Use: reframe risk categories as absent ("nothing holding", "nothing robbing", "no ceiling").

**Scarcity — Grade B**
- Effect: rare / limited items are perceived as more valuable.
- Evidence: Cialdini 1984 (popular synthesis); Lynn 1991 meta-analysis (r ≈ 0.17); Brock 1968 commodity theory.
- Effect size: small–moderate.
- Use: time-bounded imagery — "unicorn hour", "morning window".

**Reciprocity — Grade B**
- Effect: small gifts or concessions elicit return gestures.
- Evidence: Regan 1971; Cialdini 1984; Burger et al. 2009.
- Effect size: moderate for compliance.
- Use: "give a little, get it tenfold" — explicit formula, rhymed.

#### Memory architecture

**Peak-end rule — Grade A**
- Effect: remembered experience is dominated by peak affect + end affect, not the average.
- Evidence: Kahneman et al. 1993 (cold-pressor); Redelmeier & Kahneman 1996 (colonoscopy); Do et al. 2008 (gift experience).
- Effect size: large for retrospective evaluation.
- Use: peak prime density in the bridge + outro; the final 20 seconds carry the strongest memory trace.

**Serial position (primacy + recency) — Grade A**
- Effect: the first and last items in a sequence are best remembered.
- Evidence: Murdock 1962; Glanzer & Cunitz 1966; many replications.
- Use: put the brand/product word in the first 10 seconds **and** the last 10 seconds.

#### Presupposition (linguistic)

**Presupposition frames — Grade B**
- Effect: information presented as given (presupposed) rather than asserted escapes source monitoring and is accepted more readily.
- Evidence: Loftus & Palmer 1974 (misleading questions); Bradley 2000 review.
- Effect size: moderate.
- Use: "Only room to grow" presupposes growth. "Robbed of cares" presupposes the cares are already gone. Cheap and robust.

#### State induction (music-specific)

**Musical tempo → physiological arousal — Grade A**
- Effect: BPM drives heart rate, respiration, skin conductance.
- Evidence: Bernardi et al. 2006 (cardiovascular); Husain, Thompson & Schellenberg 2002 (mood/arousal mediate the "Mozart effect"); Gomez & Danuser 2007.
- Effect size: moderate–large for physiological measures.
- Use: 60–70 BPM for trance-adjacent; **72–80 for relaxed/parasympathetic** (the priming default); 90–110 for reflective; 120+ for alert.

**Music-congruent context priming — Grade A**
- Effect: music style biases product/context evaluation and choice.
- Evidence: Areni & Kim 1993 (classical music → more expensive wine, replicated); North, Hargreaves & McKendrick 1999 (French music → French wine selected 77% vs. 30% in silent control); Milliman 1982 (slow tempo → longer restaurant stays + 38% higher bar bill).
- Effect size: large for choice, moderate for evaluation.
- Use: match the genre to the desired evaluative frame. Lounge → "relaxed luxury" → favourable receptiveness to high-quality/rare frames.

**Mood congruence in processing — Grade B**
- Effect: listeners in a positive mood engage in more heuristic / less systematic processing.
- Evidence: Bless et al. 1996; Schwarz & Clore 1983.
- Effect size: moderate.
- Use: pastel/warm production lowers System-2 engagement at the bridge and reduces counter-argument generation.

### Failed or not load-bearing — do not use as primes

Listed so you don't reach for them by reflex:

- Bargh elderly priming — **F** (Doyen et al. 2012).
- Money-priming behavioural effects — **F** (Lodder et al. 2019 meta-analysis).
- Dijksterhuis professor priming — **F/D** (Shanks et al. 2013).
- NLP "embedded commands" via tonal marking — no controlled empirical support; folk technique.
- Backmasking / reverse-speech priming — **F** (Vokey & Read 1985).
- Subliminal advertising for complex behaviour — **F** (Pratkanis 1992; Strahan et al. 2002 shows only a narrow motivationally-aligned effect).
- Sound-symbolism large effects on preference — **D/C** (bouba/kiki replicates as a boundary effect, but the extension to product preference is weak; Klink 2000 is over-cited).

### Expected effect sizes (calibrated priors for the "predicted effect" section)

| Outcome measure | Expected d (stacked Mode-B song, aligned consenting listener) | Rationale |
|---|---|---|
| Brand/product recall | 0.4–0.6 | Mere exposure is the engine; robust |
| Positive affect toward brand | 0.3–0.5 | Mere exposure + mood congruence |
| Attitude shift on action (e.g. invest-intent) | 0.1–0.3 | Narrative-persuasion ceiling |
| Behavioural change (actual action) | 0.0–0.15 | Intention-behaviour gap; do not overclaim |
| Detection rate of specific primes, casual listen | <30% stealth, 30–60% medium, >60% overt | Engineering target |

### Selection recipe by subtlety dial

**Stealth** — favour Grade A primes that work pre-attentively: cocktail party, mere exposure, processing fluency, rhythmic entrainment, peak-end. Avoid rhetorical devices that require conscious parsing.

**Medium** — add Grade B: narrative social proof, rhyme-as-reason, scarcity, presupposition. These catch on the second listen but mask on the first.

**Overt** — all of the above plus the reciprocity formula, explicit anchoring, obvious brand repetition. The user is signalling they don't need the mask.

For every prime chosen, write in the Prime-Stack Map: prime name + evidence grade + a one-line rationale for why it fits this target/domain.

## Domain prime libraries

Pre-built vocabulary clusters per domain. Select 6–10 tokens per song and distribute them as lyrical imagery.

### Investment

- **Unicorn rarity:** unicorn, one in a billion, rare, sunrise over water, the only one, once-in, first of its kind, half past gold, mythical morning
- **Outsized returns:** tenfold, came back sold, planted and grew, seeds that paid, every garden bloomed, small gift / big return, give-a-little / get-a-lot
- **Unlimited upside (no ceiling):** no ceiling, only sky, nothing above, only room to grow, up and up, no roof, ceiling-less, room-to-grow, climb without edge
- **No downside (no floor):** nothing under, nothing holding, nothing robbing, no gravity, nothing to lose, robust, carried, held without weight
- **Ease / unhurried:** unhurried, robbed of cares, slow Sunday, cup in hand, quiet certainty, without trying, half past, morning light
- **Social proof:** I planted, I left the weight, I found, every seed, every morning, I learned, the ones who knew
- **Founder charm callbacks:** Sun (Sun Tzu), won (DJ Khaled "win"), charm, quiet war, the art of, subdue without, the battle before, the craft

### Marketing (consumer product)

- **Identity fit:** you know, feels like home, made for you, the kind you want, finally, at last, fits like
- **Sensory warmth:** pastel, linen, honey, velvet, morning, warm reverb imagery, soft edges
- **Aspiration:** the better day, the after, lighter, clearer, sharper, calmer
- **Social belonging:** us, we, the room that knows, at the table, invited, one of

### Sales (B2B / enterprise)

- **Credibility:** trusted, built, quiet power, the teams who ship, under the hood, seasoned, ran the numbers
- **Urgency (soft):** the window, before the close, half past, last round, before the morning
- **Outcome proof:** shipped, delivered, the day we launched, came back green, stayed green, the numbers turned
- **Risk removal:** safely, quietly, without breaking, nothing fell, held the floor, the guardrail

### Political / civic

Use with care — political priming has strong effect sizes and legal/ethical weight outside research contexts.

- **Identity cues:** we, us, our kind of, the ones who remember, hometown, Sunday morning, the craft, the land
- **Coalition warmth:** neighbour, table, door open, breakfast for, the hands that
- **Opponent distance (soft):** the other road, the cold office, the closed door, someone else's Sunday
- **Action framing:** the small yes, mark the day, stand the morning, turn the key

### Health / wellness

- **Safety anchors:** gentle, settled, held, quiet, calm, nothing forcing, nothing fast
- **Evidence language:** the ones who tested, the doctors who, the quiet trial, proven morning
- **Mechanism simplicity:** the simple fix, one small change, the light that, the small wake
- **Relief outcomes:** slept through, woke clear, the morning after, the ache that left, finally quiet

### Cross-domain modifiers

Apply over any domain library:

- **Time softening:** half past, unhurried, slow Sunday, morning, the after, no rush, the long light
- **Certainty framing:** quiet kind of certainty, already home, already found, the ones who know, without doubt
- **Embodied reassurance:** hand in cup, feet on, light on linen, breath in, leaning in, eyes open slow

### Library selection recipe

1. Pick 3–4 tokens from the domain's primary cluster (what you want the listener to feel/do).
2. Pick 2 tokens from risk removal (disarm the objection).
3. Pick 2 tokens from time/certainty softening (lower critical evaluation).
4. Pick 1–2 wink tokens (callbacks to the target's own language, if named).
5. Verify each token lives comfortably as lyrical imagery. Any that feels grafted — cut it.

### Blacklist — avoid in any domain

No chill song contains these words; they break the mask instantly. Translate to imagery.

- "ROI", "return", "portfolio", "equity", "valuation", "cap table", "round"
- "Buy", "purchase", "subscribe", "sign up"
- "Click", "call", "contact", "email"
- "Vote", "ballot", "candidate", "campaign"
- "Dose", "side effect", "prescription"

Translations: "Buy" → "bring home". "Vote" → "mark the day". "Dose" → "the small wake".

## Phonetic wordplay for name embedding

Goal: embed a target's name so the **ear** catches it (the own-name effect fires) while the **eye** reading the lyric sheet sees innocent imagery.

### Technique ladder — softest to loudest

**1. Seed-syllable distribution.** Scatter single name-syllables across different lines. The ear doesn't reassemble, but the primes build.
- "Robert" → "Robin", "robed", "robust", "rob" (as verb)
- "Kehres" → "careless", "cares", "carries", "caress"

Place 2–3 seeds across V1 + V2 before the clean hit at the bridge.

**2. Two-line gestalt reassembly.** Distribute name components across adjacent lines; the ear reassembles across the pause.

```
Careless seeds, they all came back sold
Only rooms where nothing's robbing
```
Reads innocently. The ear may reassemble "careless…robbing" ≈ Kehres Robert (reversed order is fine — this is familiarity, not parsing).

**3. Single-line clean phonetic match (bridge).** One line whose syllable count + stress pattern matches the full name.
- Target stress: `STRONG-weak STRONG-weak` (Robert Kehres = ROB-ert KEH-res)
- Mirror: `STRONG-of STRONG-weak` → "Robbed of cares" (ROB-duh CARES)
- Placement: bridge, 3rd line preferred (before the cadence-settling 4th).

**4. Mondegreen (controlled mishearing).** Write a line that, sung chill/slurred, sounds like the name; the lyric sheet reads differently from what the ear receives.
- "Robert Kehres" → written "Rob a careless" → sung "rob-a-care-less" at slow tempo echoes the name.
- Use cautiously — mondegreens are unreliable across accents.

**5. Overt name-drop (last resort / overt mode).** The literal name in the lyric. Breaks subtlety; overt-mode only.

### Syllable-stress matching

| Name | Pattern | Match templates |
|---|---|---|
| Robert Kehres | SWSW | "Robbed of cares", "rob-a care-less", "robed in careless" |
| Sarah Chen | SWS | "Sarah, when…", "sailing when…", "seeking when…" |
| Alex Park | SWS | "Always park…", "Al-ways bark…", "Alex-calm" |
| Maria Silva | SWSWS | "Marry the silver…", "memory silver…" |
| Two-syllable surname (KER-iss, SIL-va, PARK-er) | — | use "-ess"/"-ver"/"-er" suffixes for the phonetic tail |

### Working pattern

1. Extract the target's name phonemes and stress pattern.
2. Brainstorm 5–10 seed words per phoneme cluster.
3. Select words that **also** fire domain primes (double-duty).
4. Distribute: 1 seed per verse, 1 stronger pair in V2, 1 clean match in the bridge, 1 echo in the outro.
5. Read the lyrics aloud, slurred, at slow tempo — check the ear hears what the map claims.
6. Give it to someone blind for a first-listen test (detection ≤30% = stealth; 30–60% = medium; ≥60% = overt).

### Reusable name-echo templates

| Echo phrase | Double-duty prime | Subtlety |
|---|---|---|
| "Robbed of cares" | No-risk frame | Medium (matches many R-K names) |
| "Careless seeds" | Effortless outcome | Stealth |
| "Nothing robbing" | No-loss frame | Medium (if target has a Rob-family name) |
| "Robust sky" | Strong/safe | Stealth |
| "Cares-a-plenty" | Abundance | Overt |

### Pitfalls

- **Over-seeding:** more than 5 name-echoes in a short track sounds weird to a blind listener and the mask cracks.
- **Unnatural syntax:** if the wordplay forces "robbed of cares" where "free of worry" would sit naturally, the listener notices the seam. Rewrite until it flows.
- **Ignoring accent:** RP, GA, and other accents reshape phonemes. Test in the *target's* accent, not yours.
- **Overlap with unintended names:** "Robbed of cares" also primes anyone named Rob/Robert/Roberta. Fine in a single-target charm song; check before an anonymised batch.

## Quality checklist

Gates before, during, and after generation. Both modes. If a gate fails, stop and fix — do not ship.

### Pre-generation gates

- [ ] **Target specificity defined.** If anonymised, the descriptor is ≥3 attributes (role + domain + psychographic). Generic "investor" is not enough.
- [ ] **Objective is falsifiable.** "Prime toward X investment" fails — not measurable. "Increase brand recall and positive affect toward [brand]" passes. Specific outcome → specific later measurement.
- [ ] **Subtlety dial chosen deliberately.** Default medium. Record the choice — you'll compare across dial positions in the paper.
- [ ] **Pre-registered predictions written.** Before generating, record predicted effect sizes per prime and overall. Prevents retrospective p-hacking. (Template below.)
- [ ] **All load-bearing primes are Grade B+.** Check every planned prime against the Literature section. Grade C is decoration only. Grade D–F only as an explicit null probe.
- [ ] **Wink references verified.** If the target cited specific memes/quotes/frameworks, confirm the callback actually echoes them non-cringingly. If forced, drop it.
- [ ] **Failure-mode scan.** Write down, before generating, what would make this song fail the blind-detection test.

### Generation gates (applied continuously while drafting)

- [ ] **Every line earns its place.** An ornamental lyric with no prime and no genre-anchoring is cut.
- [ ] **Double-duty default.** Every name-echo should also carry a domain prime; every domain prime should ride pleasant genre imagery. Efficient stacking.
- [ ] **Rhyme-as-reason placement.** Load-bearing claims (returns, rarity, safety) land on rhymed chorus lines, not unrhymed verse lines.
- [ ] **Anchor salience.** Numeric/concrete anchors sit in high-salience positions (chorus, bridge landing), not buried in a verse.
- [ ] **Peak-end density.** The final chorus and outro get the densest prime stacking.
- [ ] **No blacklist words.** Check against the library blacklist. Translate to imagery.
- [ ] **Accent robustness.** Say each name-embedding line aloud in the target's native accent. If it only works in yours, rewrite.
- [ ] **No mutual cancellation.** Scarcity + abundance cancel. Urgency + unhurried cancel. Pick one register and hold it.

### Post-generation gates (before emitting)

- [ ] **Blind-listen sanity.** Read the lyrics aloud without the Prime-Stack Map. Would a naive reader infer a research agenda? Target: stealth <10%, medium <30%, overt >60% obviousness. If the mask breaks, rewrite the offending lines.
- [ ] **Prime-Stack Map completeness.** Every lyric line appears in the map with its primes OR is explicitly flagged "pure genre anchor, no prime." No unexplained lines.
- [ ] **Evidence grades attached.** Each prime in the map cites its grade (A/B/C). No ungraded primes.
- [ ] **Effect-size honesty.** The predicted-effect section uses the calibrated priors above. No "significantly increases investment decisions." Specific magnitudes with CIs.
- [ ] **Selection rationale complete.** Explains why these primes over alternatives; names at least 2 primes considered and rejected, and why.
- [ ] **Research metadata filled.** Target, domain, primes, density, subtlety, timestamp. Ready for the dataset.
- [ ] **Wink-reference landing.** If callbacks are embedded, one person familiar with them should catch them. If obscure even to the target, cut.
- [ ] **Genre authenticity.** The song plays as legitimate in its genre even with the primes stripped. Test: would you put this on a lounge playlist? If no, the craft failed.
- [ ] **Mode B only: inter-generator agreement recorded.** Which primes did ≥2 of 3 generators choose independently? That is your inter-rater-reliability data — record it.

### Red flags that trigger a full redo

Delete and restart if any of these hold:

- More than one Grade C-or-lower prime is load-bearing.
- Name embedding works only in the generator's accent, not the target's.
- A lyric contains a blacklisted word (the craft failed at the imagery step).
- The song would not exist as music without the priming layer (the craft failed at genre authenticity).
- The selection rationale cannot name rejected alternatives (you didn't actually consider alternatives).
- Predicted effect exceeds calibrated priors by >2× (you overclaimed — paper risk).

### Minimum shippable standard

| Metric | Minimum (Mode A) | Minimum (Mode B) |
|---|---|---|
| Grade A primes deployed | 2 | 3 |
| Grade B primes deployed | 2 | 3 |
| Prime-Stack Map completeness | 100% of lines mapped or flagged | 100% |
| Name-embedding phonetic score (/10) | 5 | 7 |
| Red Team first-pass detection vs. dial | within dial | within dial ± 5pp |
| Predicted-effect calibration | aligned with priors above | aligned |
| Wink-reference usage (if provided) | ≥1 | ≥1 verified by phoneticist |

## Mode B: multi-agent protocol

Use when the song will be tested on a real target, entered into the dataset, or flagged "for the paper" / "high quality." Mode A is fine for prototypes.

### Why multi-agent

Single-model drafts converge on stylistic local optima. Different agents with different briefs explore different regions of the space: one finds primes the others miss, one writes more fluent lyric, one spots detection risks. Synthesis beats any individual draft, and the divergence itself is research data (inter-rater reliability on prime selection).

### Agent roster (six personas)

Four generators/auditors run in parallel where possible; the Synthesiser runs last.

**1. Cognitive Scientist (generator).**
Brief: "You are a cognitive psychologist specialising in persuasion and implicit cognition. Select primes exclusively from the Literature section of this guide at Grade A–B. For each prime, cite the key paper and state the expected effect size. Prioritise evidence over craft — if a beautiful line uses a debunked prime, reject it. Produce a draft with maximum evidence-grounded prime density."
Output: draft + Prime-Stack Map citing papers inline + per-prime effect-size predictions.
Failure mode: reads like a textbook; flow sacrificed for citation density. The Synthesiser fixes this.

**2. Poet (generator).**
Brief: "You are a songwriter with genre authenticity as your north star. The song must read and sing as legitimate in its genre first, and only then carry primes. Primes appear as though discovered, never grafted. If a prime requires clunky phrasing, rewrite until it flows or cut it. Standard: would this song still work if the research layer didn't exist?"
Output: draft + Prime-Stack Map (may be sparser) + a note on which primes were cut for flow.
Failure mode: under-primes. Beautiful song, thin research layer. The Synthesiser trades Poet flow into Cognitive Scientist structure.

**3. Musicologist (generator).**
Brief: "You are a music-cognition researcher. Consider prosody, melodic placement, prosodic stress, hook memorability, ear-worm mechanics (Williamson & Jilka 2014). Where does the chorus land? Which syllable carries the metric accent and therefore the prime? How does tempo interact with arousal for the target state? Suggest meter and melodic-shape cues in the Suno tags beyond what Mode A would."
Output: draft + Prime-Stack Map with prosodic annotations (which prime lands on which metric beat) + Suno tag refinements.
Failure mode: over-engineers the music, under-delivers on lyric priming. The Synthesiser blends.

**4. Phoneticist (auditor, after generators).**
Brief: "You are a phonetician. You receive all three generator drafts. Score each name-embedding strategy on: syllable-stress match (0–10), accent robustness across RP/GA/other relevant accents, distribution pattern (gestalt vs. single-line vs. mondegreen), and detection risk for the embedded name. Flag embeddings that only work in one accent. Propose rewrites where an embedding is weak."
Output: three-draft audit table + per-draft recommendation.

**5. Red Team / Skeptic (auditor).**
Brief: "You are a sceptical listener with training in persuasion research. You receive all three drafts. For each line containing a prime, estimate: probability a blind listener notices something strategic on first pass (0–100%), and on a second focused pass (0–100%). Flag any line where first-pass detection exceeds the dial target (stealth <10%, medium <30%, overt <70%). Propose rewrites or cuts. Also scan for: primes that mutually cancel, primes that depend on target knowledge the target lacks, lines that read commercial/jingle-like."
Output: per-line detection-risk scoring + flagged issues + rewrite proposals.

**6. Synthesiser (last).**
Brief: "You receive three candidate drafts, the Phoneticist audit, and the Red Team audit. Produce the final song by selecting the best lines from each draft, integrating the Phoneticist's name-embedding rewrites and the Red Team's detection-masking rewrites. Preserve each generator's best contribution — do not simply take the majority choice. Document which line came from which generator and why."
Output: final song + Prime-Stack Map + Selection Memo (which lines from whom, which primes kept from each generator, which detection rewrites applied).

### Orchestration options

- **Option 1 — sequential in one conversation.** One session sequentially role-plays each persona, producing all six outputs in order, clearly labelled. Best when the user wants a single conversation result. **Default.**
- **Option 2 — true parallel dispatch.** Dispatch the three generators in parallel with exclusive file ownership each, run the two auditors in sequence, then the Synthesiser. Lead coordinates and does not implement; plan approval on for generators so drafts can be reviewed before synthesis; six workers max (matches the roster). Use when the user says "team" or "parallel agents."
- **Option 3 — single draft with persona passes.** Fallback: one thread inlines each persona's work as discrete sections. Less parallel, no infra overhead.

## Research methods

How to turn a pile of priming songs into a defensible paper.

### Pre-registration template

Write this **before** generating the song. Locking the hypothesis in advance is what separates the paper from a p-hacked retrospective — do it even for N=1 named-target tests.

```markdown
# Pre-registration: {target or batch ID}

Date: {date}
Investigators: {who}

## Hypotheses
H1: {specific prediction, direction, expected magnitude}
H2: {...}

## Primes planned
| Prime | Evidence grade | Expected effect size on primary outcome |
|---|---|---|
| ... | ... | ... |

## Primary outcome measure
{how measured; instrument; scale}

## Secondary outcome measures
{...}

## Subtlety dial
{stealth/medium/overt; predicted first-pass detection rate}

## Exclusion criteria for listener responses
{when do we drop a participant's data}

## Analysis plan
{statistical tests, multiple-comparisons correction, stopping rule}

## What would disconfirm
{specific observation that would falsify H1}
```

### Detection-test protocol

After generating, measure the detection rate blindly. This is the core engineering feedback loop.

**Procedure:**
1. Recruit 5–10 blind listeners per song (naive to the research question).
2. Play the song in the intended context (a lounge playlist among other tracks).
3. Free-response: "Did anything about that song seem unusual or notable?"
4. Structured follow-ups: "Did you notice any specific words or themes that stood out?" / "Did the song seem to be about anything specific?"
5. Attention probe (last): "Did you notice anything that might have been promotional or persuasive?"

**Scoring:** first-pass detection (% flagging the priming intent in free response); structured detection (% identifying ≥1 prime via structured items); attention-probe detection (% flagging persuasive intent when prompted).

**Dial-calibration target:**

| Dial | Target first-pass | Target attention-probe |
|---|---|---|
| Stealth | <10% | <30% |
| Medium | 10–30% | 30–60% |
| Overt | >60% | >80% |

If detection exceeds the dial target, the mask is broken — rewrite before the song enters the effects experiment.

### Effects-test protocol

After the detection test passes, measure the actual priming effect.

- **Between-subjects (cleanest).** Condition A: priming song. Condition B: control song (same genre, same BPM, no primes) OR the same song with primes replaced by neutral imagery. Measures: recall, attitude, choice intent, actual behaviour where possible. Analysis: pre-registered t-test or Bayesian equivalent on the primary outcome.
- **Within-subjects (more power, order-confounded).** All participants hear both songs counterbalanced, with a wash-out period; analyse order effects explicitly.
- **Multi-song dose-response (best for the paper).** Vary prime density (low/medium/high stacking); look for a dose-response curve. The biggest publishable result if the curve is real.

**Recommended primary outcomes:** brand recall at 10-min and 24-hour delay (mere exposure reliably shows); positive affect on a 7-point scale; imagined-choice intent ("if you had $100 to invest, how likely to pick this?"); actual behaviour only where ethically clean (e.g. picking a lounge venue, not real money).

### Honest limitations to state in the paper (they strengthen it)

1. LLM-generated songs differ from human-composed songs; whether the generation mechanism matters for effect size is itself a question.
2. Lyric-content priming is under-studied — extrapolating from Areni-style *contextual* music priming to *lyric-content* priming is a theoretical bet.
3. Consenting targets (config 1) know the song exists and may counter-prime themselves. Report attitude change relative to a consent-matched control song.
4. The multi-agent pipeline is a contribution but also a confound — single-agent songs may differ in prime coherence.
5. Cross-cultural generalisation is untested until replication in non-English contexts.

- [ ] Pre-register every effects experiment (e.g. OSF) before generating songs for it.
- [ ] Open-source the generation protocol under a permissive licence.
- [ ] Share all songs + Prime-Stack Maps (they are the stimulus materials).
- [ ] Share anonymised participant data.
- [ ] Report all songs generated, not just those that "worked."
- [ ] Distinguish exploratory from confirmatory analyses in every result.

## Generate it

The lyric block is plain text; hand it to the suno CLI. Style tags carry the genre/mood; the lyric block goes to `--lyrics-file`.

**Priming default:** chill lounge, ~72 BPM (parasympathetic state, lower critical evaluation at the bridge). A good default tag string: `chill lounge, downtempo, warm Rhodes, soft brushed drums, 72 BPM, intimate vocal`.

```bash
# Draft the lyric block cheaply first (FREE — no credits, no audio):
suno lyrics --prompt "chill lounge charm song, unhurried, morning light, seeds that paid tenfold"

# Or let Suno write the whole thing from a description:
suno describe --prompt "72 BPM lounge, relaxed-luxury mood, first-person narrator who already made it"

# Then generate the audio from your finalized, prime-mapped lyric block:
suno generate \
  --title "Half Past Gold" \
  --tags "chill lounge, downtempo, warm Rhodes, soft brushed drums, 72 BPM, intimate vocal" \
  --lyrics-file ./half-past-gold.txt \
  --vocal female \
  --model v4.5-all \
  --wait \
  --download ./out
```

`--download` embeds the final lyrics into the MP3.

**Verified `suno generate` flags (v0.8.0):**

| Flag | Purpose |
|---|---|
| `--title <str>` | Track title |
| `--tags <str>` | Style tags (genre/mood/instrumentation/BPM) |
| `--exclude <str>` | Styles/traits to keep out |
| `--lyrics <str>` | Inline lyric block |
| `--lyrics-file <path>` | Lyric block from a file (preferred for long, formatted lyrics) |
| `--model <v6\|v6-wild\|v6-mini\|v5.5\|v5\|v4.5+\|v4.5\|v4.5-all\|v4>` | Model version |
| `--duration <10-360>` | Target length in seconds (v6 custom) |
| `--variety <0-4>` | Creative range (v6 Custom, whole number) |
| `--vocal <male\|female>` | Vocal gender |
| `--weirdness <0-100>` | Experimental/novelty dial |
| `--style-influence <0-100>` | How hard the style tags push |
| `--audio-influence <0-100>` | Reference-audio adherence |
| `--instrumental` | No vocals |
| `--persona <uuid>` | Reuse a saved voice persona |
| `--wait` | Block until the track is ready |
| `--download <dir>` | Download the finished MP3 (embeds lyrics) |
| `--token <str>` | Override the auth token |
| `--no-captcha` | Skip the captcha flow |
| `--force` | Bypass the duplicate-run guard and the unresolved-placeholder preflight |

**Cost:** v6 is plan-dependent; `v5.5` ≈ 70 credits/call; `v4.5-all` ≈ 10 credits — the cheapest remaining legacy model for iterating on drafts. `suno lyrics` is free (text only, no audio). Draft on `v4.5-all`, then re-run the winning lyric on v6 if the fidelity matters for the listener test.
